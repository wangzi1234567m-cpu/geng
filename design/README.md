# 考梗记视觉设计

本目录保存页面视觉提案及设计来源，不代表页面已经实现。当前先探索三页：空间列表、空间内梗列表、记录编辑页。

## 当前方向

正式名称已改为“考梗记”。在第一版基础上探索更有趣的朋友双人空间：用双人身份、原话气泡、轻量贴纸和手写批注的视觉语言，突出“这句只有我们懂”的共同记忆。权限、保存和冻结状态仍须清晰；装饰不变为未经确认的互动按钮。

第一版“朋友的梗”保留为历史提案，不再作为当前命名规范。第二版的色彩、插画、布局与微文案属于待评审提案；不自动加入新业务功能。

当前视觉稿：[考梗记双人空间 v2](ui-concept-v2.png)。使用内置 imagegen 以第一版为参考改绘，保留独立文件；[最终提示词](ui-concept-v2-prompt.md)已保存。

已查看 v2：品牌为“考梗记”，三页对应空间列表、空间内梗列表和新建记录。主要变化是双人插画、原话气泡、纸张与贴纸装饰；冻结只读和默认作者权限仍可见。插画与装饰不是已实现的头像定制、贴纸收集或游戏功能。最终品牌字形、文案与图片细节应在原型和代码中精确实现。

## 首轮方向

简洁、亲切、易读的原生 Android 界面；突出朋友之间梗的文字、背景和图片，不使用情侣关系、公开社区、排行榜、打卡、聊天或 AI 功能作为默认设计。具体配色与风格尚待反馈，不是已确认品牌规范。

示例名字、文字、时间和图片仅用于演示。编辑页默认仅作者可编辑和删除，空间状态与权限表达必须符合已有需求；冻结页及删除、注销确认等会在后续完整原型中补齐。
